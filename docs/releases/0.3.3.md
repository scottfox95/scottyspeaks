# SS2 0.3.3

Restores the standard macOS title bar for the control panel. Close/minimize/zoom buttons now sit in native chrome above the read-aloud toolbar. macOS owns title-bar dragging. The obsolete in-content drag spacers were removed, and the sidebar logo no longer selects when dragged. Voice settings and Stop reading explicitly remain clickable in draggable toolbars on other platforms.

Validation: TypeScript and renderer build passed; the full ControlPanel synthetic Electron suite passed with native window configuration, toolbar click checks and the existing long transcript/layout/rename/export tests. The speech fixture passed settings, stop, recording inhibition and playback checks. Signed package source and renderer matched the workspace and its bundled helpers/native database loaded. Native chrome was visually inspected.

Automation limitation: CUA drag gestures did not produce a measured window-position change even with the standard native macOS title bar, so a physical mouse drag is not claimed as tested. The final implementation relies on standard macOS window chrome, rather than a custom draggable region. Electron documents that OS chrome supplies the default drag behavior: https://github.com/electron/electron/blob/main/docs/tutorial/custom-window-interactions.md

Installation and archive preservation checks are recorded under `.superpowers/titlebar-0.3.3/`. No real call content was changed or played during testing. No commits or pushes were made.
