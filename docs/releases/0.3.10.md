# SS2 0.3.10

Local call transcripts are now split into speaker paragraphs. A new native helper (`call-diarizer`, NVIDIA Nemotron 3 on the Neural Engine) runs once per transcription; the person on this Mac's microphone is labelled "Microphone", everyone else gets a numbered speaker you can rename. This only applies to calls transcribed on this Mac with Parakeet on the Neural Engine; Whisper, CPU Parakeet and cloud transcription are unchanged. The first transcription downloads about 190 MB of model files.

The Dictation view can search the whole history, including the original wording before edits, and loads older entries 50 at a time. Call notes gained a search box, list previews with durations, a "Record a call" button, "Mark moment", "Action item" and outline buttons, and "Add to notes" from any transcript line. Stopping a recording no longer waits on a pending save.

The sidebar is grouped (Workspace / Make it yours), remembers the last view and answers ⌘1/⌘2/⌘3. A quick press-and-release while the microphone is still opening now cancels cleanly instead of reporting a microphone error. Dictation polish uses the application captured at recording start rather than whichever window is in front when the transcript arrives. Non-English UI languages load on demand.

Version 0.3.9 on GitHub (published October 14) was built from the September 10 code; this release is the first that carries the September 24 work.
