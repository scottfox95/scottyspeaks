# SS2 0.3.12

**Screen recording.** A new **Screen recordings** page (sidebar, or ⌘4) records the whole screen, another display, or a single window, with system audio and your microphone. Call notes recording is unchanged and can run at the same time.

- Built for long sessions: the recording is written to disk as it goes (a fragment every 5 seconds), so memory stays flat over hours and a crash or power cut keeps everything up to the last few seconds. The Mac is kept awake while recording.
- Compressed: HEVC video at 15 fps, long side capped at 1920 px, about 1.2 Mbps, plus AAC audio. When you stop, the two audio sources are mixed into one track and the file is saved as an `.mp4`. Measured: a 10-minute busy test (scrolling document, moving window, constantly changing camera tile, two audio sources) came to 67.6 MB, about **0.4 GB per hour**. The bitrate cap keeps the worst case near 0.6 GB per hour, and a mostly static screen uses far less.
- Files go to `~/Movies/SS2 Screen Recordings/` and are listed on the page with Play, Show in Finder and Move to Trash.
- SS2 won't start with less than 2 GB free, and stops and saves if free space falls below 1 GB.
- **First time on each Mac:** macOS asks for Screen & System Audio Recording permission. Allow it, then quit and reopen SS2. If it was denied, the page shows a button that opens the right System Settings pane.

Requires macOS 15 or later (Apple silicon).
