# SS2 0.3.6

Call transcription is now recoverable when a provider or model produces a bad result. **Transcribe again** lets you retry with a different local model or OpenRouter key, bypasses stale cached output, preserves the existing transcript if the retry fails, and clears superseded speaker names after a successful replacement. OpenRouter authentication, credit, and empty-response failures now show actionable messages.

Local transcription mixes synchronized microphone and call-audio tracks into one conversation before transcription, preventing the same call from appearing twice. The audio player can export the selected microphone, call-audio, or combined source as an MP3 for independent recovery or sharing.

Stored OpenRouter keys are decrypted at most once per SS2 launch and retained only in Electron's main-process memory. Replacing or removing the key updates that memory immediately, so repeated transcriptions no longer request repeated Keychain access during the same app session.
