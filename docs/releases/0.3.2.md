# SS2 0.3.2

Call transcript usability update.

- The folder destination controls occupy their own area below the scrollable call content. Long transcripts can be read to the end without text running underneath the controls.
- Cloud speaker identifiers display as Speaker 1, Speaker 2, and so on. Imported speaker names stay intact. Speaker labels describe voices, while timestamps indicate playback position.
- Speaker controls provide a transcript excerpt and a listening action to help identify the voice. Naming a speaker updates that label throughout the structured transcript and subsequent Markdown exports.
- Labels from separate audio parts remain distinct. Manually edited transcript text remains under the user's control.
