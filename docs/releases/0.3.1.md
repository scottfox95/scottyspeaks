# SS2 0.3.1

Installed September 7, 2026 (local time).

- Call notes now has a visible **Add folder…** header action, including when no call is selected. It opens a directory chooser attached to the window and selects the pinned folder after you choose one.
- Select a call and use **Delete call**. The confirmation starts on Cancel and explains permanent removal of the app-owned call, recordings and agent drafts. Exports and original imported files remain untouched. Recording, transcription and pending capture/playback preparation block deletion.
- Fixed the Markdown editor intercepting clicks on the sticky footer in smaller windows.

Final verification: 172 unit tests, TypeScript, renderer build, ten locales, actual synthetic Electron UI and independent review passed. Signed package/source/native database checked; installed controls and cancellation verified. All existing call/key/config files and history count remained unchanged. Current local data and prior app bundle were backed up. No real calls were deleted or real folders pinned during testing.

Work-Mac archive: `/Users/scottfox/Desktop/SS2-0.3.1-arm64-2026-09-08.zip`; embedded version and archive integrity verified. Older archives retained. Source remains on the existing branch without committing or pushing.
