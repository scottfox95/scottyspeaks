# SS2 0.3.0 — delivered September 7, 2026

Installed at `/Applications/SS2.app`, signed with the existing local identity. The app is open on Call notes. Source changes remain on `codex/reliable-dictation-call-notebook`; no commit, merge, push, or external agent configuration was performed.

## What changed

- History replay and repair: retained audio, immutable raw/final text and settings, explicit re-transcription previews, and local correction examples. Ordinary dictation audio retention is Off/1/7/30 days, default 7; explicit examples remain until deleted.
- Call evidence: source playback, timestamp seeking and multiple takes; human transcript edits survive recognition, while original machine segments remain separate.
- Cleanup: explicit exact wording, filler/self-correction/technical-text controls and truthful processing states.
- Paste targeting: original field verification and clipboard transaction protection, with manual-copy recovery when verification fails. Verified SS2 editor targets are eligible too.
- Agents: individual call grants/revocation, separate evidence-linked drafts, and a one-time Markdown handoff that does not grant ongoing access.
- Local read-aloud: installed system voices, selected/all text, visible Stop and recording suppression. Agent spoken updates remain off by default.
- Scheduling: foreground dictation takes priority over waiting local call chunks.
