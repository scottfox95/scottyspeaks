# SS2 0.3.7

OpenRouter call transcription now uses Electron's Chromium network stack instead of Node's standalone HTTP stack. This allows SS2 to honor macOS system proxies, PAC configuration, authenticated proxies, and compatible endpoint-security traffic inspection in the same way Chromium-based apps do.

The proxy-aware transport is used for both initial call transcription and **Transcribe again** retries. Local Whisper and Parakeet transcription behavior is unchanged.
