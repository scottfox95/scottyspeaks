# SS2 0.3.5

Cloud call transcription now keeps a long recording in one diarization request. Transient provider failures retry the complete request once instead of splitting the audio into independently numbered speaker sets, preventing a three-person call from appearing as dozens of speakers. Legacy split caches are marked for safe retranscription after restart, and successful retries discard stale speaker identities.

The OpenRouter timeout scales with recording duration while remaining bounded, and transient HTTP failures retain their status for retry decisions. Regression coverage includes the original long-call timeout behavior, legacy-cache migration, stale-speaker cleanup, and complete-request retry.
