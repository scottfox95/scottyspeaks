# SS2 0.3.8

OpenRouter MAI transcription now sends at most 50 custom-dictionary phrases, matching Azure's phrase-list limit. Larger SS2 dictionaries continue to work locally, while the first 50 entries are used as cloud recognition hints instead of causing every request to fail with HTTP 400.

When OpenRouter returns another provider error, Call Notes now retains and displays a short sanitized diagnostic message. API keys, audio, long encoded values, and unrelated provider response fields are excluded.
