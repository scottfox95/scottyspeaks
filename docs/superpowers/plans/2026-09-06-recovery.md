# Dictation and Call Notebook Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development task by task. Preserve existing uncommitted work. Do not create commits containing prior changes; the controller owns integration.

**Goal:** Restore faithful dictation and deliver a local-first Mac call notebook with optional OpenRouter transcription and pinned Finder destinations.

**Architecture:** Keep dictation separate from long-running meeting capture. A main-process meeting service owns recoverable sessions, audio files, transcription, and selected filesystem destinations; a React call view edits Markdown drafts and requests explicit capture. Local engines remain available; cloud calls require the selected OpenRouter mode and a configured key.

**Tech Stack:** Electron 36, React 19, TypeScript, existing shadcn primitives, Node test runner, FFmpeg, Swift ScreenCaptureKit where required.

**Spec:** `docs/2026-09-06-product-recovery.md`, refined by Scott's answers: both computers are Macs; system audio is available; corrections are made in destination apps; all calls route through the computer; local and OpenRouter modes are required.
